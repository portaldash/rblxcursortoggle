# Roblox Cursor Toggle Tool

This is a lightweight Python script that toggles visibility of certain Roblox cursor files by renaming them. It's designed for users who want to temporarily hide their in-game cursors in Roblox when using Bloxstrap.

## Features

- Automatically detects the latest Roblox version installed via Bloxstrap.
- Toggles visibility of:
  - `MouseLockedCursor.png`
  - `ArrowCursor.png`
  - The entire `Cursors` folder
- Silent operation: No popups or output unless there's an error (logging can be added if desired).
- Executable version available for convenience (see [Releases](https://github.com/YOUR_USERNAME/YOUR_REPO/releases)).
